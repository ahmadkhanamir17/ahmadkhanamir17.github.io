No-code agents

Pick the model, write versioned prompts, attach knowledge and switch tools on or off. Each agent's LangGraph is compiled at runtime and rebuilt whenever its setup changes. A setup wizard and readiness checklist guide new agents.

Actions with guardrails

Tools look up orders, stock and warranties. Risky actions such as refunds pause until a person approves them.

Human hand-off

Low confidence or a direct request escalates the chat, opens a ticket and pauses the bot. Staff get an AI hand-over summary and an AI-drafted reply they can edit.

Memory that scales

Running summaries keep long chats sharp, and the agent remembers key facts about each customer across conversations.

Agent playground

Test any agent as a real customer before it goes live. Every reply shows its intent, confidence, tool calls and document sources.

One-line website widget

A single script tag on any website, Odoo page or shop. Streaming replies, quick-reply chips, ratings, and live human replies in the same widget. Public keys are locked to your domains.

How a message flows

  1. MemoryRunning summary and customer facts
  2. RecallRelevant older messages
  3. RetrieveHybrid search over the agent's knowledge
  4. Agent and toolsLLM calls orders, stock and MCP tools
  5. ApproveRisky actions wait for a person
  6. FinalizeIntent, confidence, follow-ups, hand-off

Production basics

AI that respects permissions

Since 2024 I've led AI work at Enseyab: assistants that answer from live Odoo data, but only with what the person asking is allowed to see.

  1. 1

    Someone asks

    A customer or employee asks on the website widget, WhatsApp or a REST API.

  2. 2

    The assistant plans

    FastAPI and LangChain pick the right tool: orders, stock, tickets, HR or policy documents.

  3. 3

    Odoo checks access

    Every lookup goes through the user's security groups and record rules, so nothing unauthorised is exposed.

  4. 4

    Answer or hand over

    The assistant replies, creates the record, or passes the conversation to a person.
